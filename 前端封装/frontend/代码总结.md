# 火电深度调峰+抽水蓄能减碳效益优化系统 - 代码总结

## 项目概述

本项目是一个基于Streamlit的电力系统优化可视化平台，用于展示"火电深度调峰+抽水蓄能"组合方案的减碳效益和优化效果。

**技术栈**：Python 3 / Streamlit / NumPy / Pandas / Plotly / SciPy

---

## 文件结构

```
frontend/
├── app.py              # 主应用文件 (Streamlit Web界面)
├── data_loader.py      # 数据加载与预处理模块
├── requirements.txt    # 项目依赖
├── A.mat               # MATLAB数据文件 (Pareto解集: 100×27×365)
├── AA.mat              # MATLAB数据文件 (最优解: 365×23)
├── wind.txt            # 风电功率数据 (365×24)
├── solar.txt           # 光伏功率数据 (365×24)
├── hydro.txt           # 水电功率数据 (365×24)
├── FH.txt              # 火电负荷数据 (365×24)
└── solution.txt        # Pareto解目标值 (100×27)
```

- 决策变量：23个 (水库状态比例)

## 核心算法

### 抽水蓄能功率计算 (`calculate_npump`)

```python
Zpump = 1400  # 抽蓄装机容量 (MW)
h = 4         # 时间步长 (小时)
V = Zpump * h # 蓄能容量 (MWh)

# 决策变量 x: 23个值，代表每个时刻结束时水库状态比例 [0,1]
# C[0] = 0.5 (初始状态)
# C[1:24] = x (23个决策变量)
# C[24] = 0.5 (周期约束)

if C[i] <= C[i-1]:  # 发电状态
    np_power = (C[i-1] - C[i]) * V
else:  # 抽水状态
    np_power = (C[i-1] - C[i]) * V / 0.75
```

### 碳减排计算 (`calculate_carbon_reduction`)

```python
Nt = fh - (N + npump)    # 有抽蓄火电负荷
Nt2 = fh - N             # 无抽蓄火电负荷
power_change = Nt.sum() - Nt2.sum()  # 火电变化量
carbon_change = power_change * 碳排放系数 / 10000  # 万吨CO₂
```

---

## 关键指标

| 指标 | 计算公式 | 单位 |
|------|----------|------|
| 新能源发电量 | N_h + N_w + N_p | 亿kWh |
| 火电减发电量 | ΔN_t = N_t2 - N_t | 亿kWh |
| 碳减排量 | |ΔN_t| × K_CO₂ | 万吨CO₂ |
| 新能源渗透率 | (N_h+N_w+N_p)/(N_h+N_w+N_p+N_t) × 100% | % |

## 技术特点

1. **数据缓存**：`@st.cache_data(ttl=3600)` 避免重复加载
2. **深色主题**：自定义CSS实现科技感UI
3. **交互筛选**：支持按月/季节/日期范围筛选数据
4. **响应式布局**：使用`st.columns()`实现多列排版
5. **数学公式**：支持LaTeX渲染（MathJax）
6. **热力图可视化**：使用Plotly实现月度分布热力图
