## 一、算法总览

### 1.1 算法全称与定位

**NSLDE** = **N**on-dominated **S**orting with **L**évy flight and **D**ifferential **E**volution

本质是在经典 NSGA-II 框架上融合三项改进机制的多目标进化算法（MOEA），专为解决抽水蓄能减碳效益优化这类**强约束、高维、多目标**调度问题而设计。

### 1.2 应用场景

> 源网荷储协同下抽水蓄能智能控碳零碳效益核算系统

在风电、光伏出力强波动性的背景下，通过多目标进化算法协调火电深度调峰、新能源消纳和抽水蓄能调度，实现电力系统低碳运行。

## 二、算法原理

### 2.1 整体框架

NSLDE 基于 NSGA-II 的经典流程：种群初始化 → 非支配排序 → 迭代进化 → Pareto 前沿输出。在三个关键环节引入了改进。

```
                    ┌──────────────────────┐
                    │  Logistic 混沌映射初始化 │  ← 改进1：增强种群多样性
                    └──────────┬───────────┘
                               ↓
                    ┌──────────────────────┐
                    │    快速非支配排序       │
                    └──────────┬───────────┘
                               ↓
              ┌────────────────────────────────┐
              │     迭代进化 (pop=100, gen=3000) │
              │                                │
              │  ┌──────────────────────────┐  │
              │  │ 二进制锦标赛选择 (tour=2) │  │
              │  └────────────┬─────────────┘  │
              │               ↓                │
              │  ┌──────────────────────────┐  │
              │  │ DE/rand/1 差分进化交叉    │  │  ← 改进2：全局搜索
              │  │ (pc=0.7, F=0.3)          │  │
              │  └────────────┬─────────────┘  │
              │               ↓                │
              │  ┌──────────────────────────┐  │
              │  │ Lévy 飞行变异             │  │  ← 改进3：跳出局部最优
              │  │ (pm=0.5, α=50, β=1.5)    │  │
              │  └────────────┬─────────────┘  │
              │               ↓                │
              │  ┌──────────────────────────┐  │
              │  │ 父子合并 + 非支配排序      │  │
              │  └────────────┬─────────────┘  │
              │               ↓                │
              │  ┌──────────────────────────┐  │
              │  │ 精英保留 (N=100)          │  │
              │  └──────────────────────────┘  │
              └────────────────────────────────┘
                               ↓
                    ┌──────────────────────┐
                    │   Pareto 最优解集     │
                    └──────────┬───────────┘
                               ↓
                    ┌──────────────────────┐
                    │  TOPSIS 折中解选择    │
                    └──────────────────────┘
```

### 2.2 三项核心改进

#### 改进1：Logistic 混沌映射初始化

**文件位置**：`initialize_variables.m` 第 29-33 行

```matlab
y(1,:) = rand(1, V);                    % 随机初值
for k = 1 : N
    for l = 1 : V
        y(k+1, l) = y(k, l) * 4 * (1 - y(k, l));  % Logistic 映射 (μ=4)
    end
end
% 映射到决策变量空间
f(i, j) = min(j) + (max(j) - min(j)) * y(i+1, j);
```

**原理与意义**：
- Logistic 映射在 μ=4 时处于完全混沌状态，生成的序列具有遍历性和伪随机性
- 相比 `rand()` 的纯随机初始化，混沌序列在搜索空间中的分布更均匀
- 有效避免初始种群聚集在局部区域，降低早熟收敛风险
- 参考：Logistic 混沌映射是混沌理论中最经典的离散动力系统之一

#### 改进2：DE/rand/1 差分进化交叉

**文件位置**：`genetic_operator.m` 第 56-58 行

```matlab
if rand(1) < 0.7          % 交叉概率 pc = 0.7
    child_1(j) = parent_chromosome(i, j) + 0.3 * (parent_1(j) - parent_2(j));
end
```

**原理与意义**：
- 采用差分进化经典策略 DE/rand/1：在当前个体上叠加两个随机父代的加权差分向量
- 缩放因子 F=0.3，较小的 F 值保证搜索的精细化
- 相比 NSGA-II 原版的 SBX（模拟二进制交叉），差分进化交叉在高维连续优化问题上具有更强的全局探索能力
- 差分向量的方向自适应地指向种群中更有希望的区域

#### 改进3：Lévy 飞行变异

**文件位置**：`genetic_operator.m` 第 63-68 行

```matlab
u.string = normrnd(0, 0.6966, 1, V);    % N(0, 0.6966²)
v.string = normrnd(0, 1, 1, V);         % N(0, 1)

if rand(1) < 0.5          % Lévy 飞行 (50%概率)
    child_2(j) = child_1(j) + 50 * u(j) / |v(j)|^(1/1.5);
else                       % 均匀变异 (50%概率)
    child_2(j) = child_1(j) + 50 * (-1 + 2*rand);
end
```

**原理与意义**：
- 基于 Mantegna (1994) 算法生成 Lévy 稳定分布随机数
- Lévy 飞行的步长服从重尾分布：大部分步长较小（局部开发），偶尔有长跳跃（全局探索）
- 步长公式：`step = 50 × u / |v|^(1/β)`，其中 β=1.5，α=50
- 关键价值：当种群陷入局部最优时，Lévy 飞行的长跳跃特性可以**跳出局部最优陷阱**，这是标准 NSGA-II 多项式变异无法做到的
- 在宁夏强约束场景中得到验证——标准 NSGA-II 0 天有效，NSLDE 实现 365 天全部有效

### 2.3 NSGA-II 标准组件

| 组件 | 文件 | 说明 |
|------|------|------|
| 二进制锦标赛选择 | `tournament_selection.m` | tour=2，基于 Pareto 等级 + 拥挤距离 |
| 快速非支配排序 | `non_domination_sort_mod.m` | O(MN²) 复杂度，分配 Pareto 等级 |
| 拥挤距离计算 | 同上 | 同一 Pareto 等级内衡量解的分布密度 |

## 三、问题建模

### 3.1 决策变量（23维）

| 变量 | 维度 | 取值范围 | 含义 |
|------|:---:|------|------|
| x(1:21) | 21 | [0, 1] | 各时段抽水蓄能状态比例 |
| x(22) | 1 | [0.125, 1] | 火电调峰深度下限 |
| x(23) | 1 | [0.3125, 0.75] | 火电最低出力系数 |

### 3.2 双目标函数

| 目标 | 优化方向 | 单位 | 含义 |
|------|----------|------|------|
| f₁ | 最小化 | MW | 火电调峰深度 Zt_f = (max(Nt) - min(Nt)) / 0.7 |
| f₂ | 最小化 | kg | 24小时火电碳排放总量 sum(EMI) |

两个目标存在冲突关系：降低调峰深度 → 抽蓄更多参与调节 → 但抽发效率损失可能增加煤耗；过度依赖火电调峰 → 碳排放随负荷率下降而急剧上升。

### 3.3 约束条件

- **功率平衡**：L = Nh + Nw + Np + Npump + Nt（负荷 = 水电 + 风电 + 光伏 + 抽蓄 + 火电）
- **抽蓄容量约束**：|Npump| ≤ Zpump（不超过额定功率）；|Npump| ≥ 0.2 × Zpump 或 Npump = 0
- **蓄能量约束**：C(t) ∈ [0, 1]（蓄能池比例在 0-100% 之间）
- **周期性约束**：C(1) = C(25) = 0.5（一天始末蓄能状态一致）
- **火电出力约束**：Nt ≥ 0（火电不反向供电）

### 3.4 火电碳排放模型（三段式分工况）

突破传统固定排放系数法，构建基于负荷率的精细化碳排放模型：

| 工况区间 | 负荷率 | 供电煤耗 (g/kWh) | 燃烧效率 | 机械效率 |
|----------|:---:|:---:|:---:|:---:|
| 深度调峰 | < 30% | **370** | 0.904 → 0.920 | 0.401 → 0.424 |
| 中度调峰 | 30% - 50% | **330** | 0.920 → 0.934 | 0.424 → 0.442 |
| 高负荷 | > 50% | **300** | 0.934 → 0.953 | 0.442 → 0.458 |

碳排放公式 = 基本排放 + 效率损失排放 + 辅助过程排放

```
Ce = H × OF × Cc × Mco2/Mc                        (基本排放)
   + H × (1 - e/e_100) × Cq + H × (1 - g/g_100) × Cq  (效率损失)
   + a × H × Cq + H × ps × us × Mco2/Ms           (辅助排放)
```

其中碳氧化因子 OF=0.99，碳含量 Cc=0.7，CO2与C分子量比 44/12，标煤排放系数 Cq=0.9183。

核心发现：一台600MW机组在30%负荷率时的供电煤耗（370 g/kWh）比满负荷（300 g/kWh）高出 **23.3%**，形成了**"调峰碳锁定"效应**。

## 五、实验结果

### 5.1 约束满足率验证（关键指标）

在四省 365 天 × 24 小时全时序优化中，对比标准 NSGA-II 与 NSLDE：

| 省份 | NSGA-II (200代) | NSLDE (3000代) | 提升幅度 |
|------|:---:|:---:|------|
| 陕西 | 365/365 | 365/365 | 基准 |
| 甘肃 | 181/365 | **365/365** | **+102%** |
| 青海 | 273/365 | **365/365** | **+34%** |
| 宁夏 | **0/365** | **365/365** | **∞** — 从无解到全解 |

宁夏从 0 天有效到全部 365 天有效，证明了 Lévy 飞行 + 混沌初始化在强约束场景下的**突破性作用**——标准 NSGA-II 在宁夏的组合约束下完全无法找到可行解，NSLDE 通过 Lévy 飞行的长跳跃能力跨越了不可行区域。

### 5.2 三算法 Benchmark 横向对比

在四省夏季典型日（种群 100、代数 200、种子 42），以 IGD 为主要指标：

| 省份 | 最优算法 | IGD | Spacing | Hypervolume |
|------|------|:---:|:---:|:---:|
| 陕西 | NSGA-II (改进) | **0.01437** | — | — |
| 甘肃 | NSGA-II (改进) | **0.02004** | — | — |
| 青海 | NSGA-II (改进) | **0.01534** | — | — |
| 宁夏 | NSGA-II (改进) | **0.01674** | — | — |

改进 NSGA-II 在四省 IGD 指标**全部排名第一**，优于 NSGA-III 和 MOEA/D。综合排名权重：IGD 0.4 + Spacing 0.3 + Hypervolume 0.3。

### 5.3 NSLDE 全时序优化结果（365天 / 8核并行）

| 省份 | 抽蓄装机 (MW) | 碳减排 (万tCO₂) | 抽水小时 (h) | 发电小时 (h) | 抽发效率 (%) | 单省耗时 |
|------|:---:|:---:|:---:|:---:|:---:|:---:|
| 陕西 | 1400 | 0.4172 | 3402 | 2672 | 75.0 | ~100 min |
| 甘肃 | 1400 | **0.5484** | 3789 | 3037 | 75.0 | ~130 min |
| 青海 | 800 | 0.2919 | 3563 | 2696 | 75.0 | ~650 min |
| 宁夏 | 600 | 0.2275 | 3639 | 2954 | 75.0 | ~100 min |

### 5.4 结果分析与发现

1. **算法鲁棒性**：四省全部实现 365/365 约束满足，无一个不可行解
2. **甘肃减碳最多**（0.55 万tCO₂）：得益于高新能源渗透率 + 1400MW 大抽蓄装机，边际减碳效益最显著
3. **抽发效率稳定在 75%**：与物理模型一致，说明优化未以牺牲效率为代价
4. **碳减排量与新能源渗透率正相关**：各省减碳排序 甘肃 > 陕西 > 青海 > 宁夏，与新能源资源禀赋一致
5. **装机边际效应递减**：青海（800MW）与宁夏（600MW）减碳量差距远小于装机差距，暗示存在最优装机规模

## 附录：关键公式一览

### A. Logistic 混沌映射

```
y(k+1) = 4 × y(k) × (1 - y(k)),   y(0) ∈ (0, 1)
```

### B. 差分进化交叉 (DE/rand/1)

```
x_child = x_i + F × (x_r1 - x_r2),   F = 0.3
```

### C. Lévy 飞行步长 (Mantegna 算法)

```
s = α × u / |v|^(1/β)
u ~ N(0, σ_u²),  v ~ N(0, 1)
σ_u = [Γ(1+β) × sin(πβ/2) / (Γ((1+β)/2) × β × 2^((β-1)/2))]^(1/β)
α = 50,  β = 1.5
```

### D. 火电碳排放

```
EMI = TH × [H × OF × Cc × Mco2/Mc + 效率损失项 + 辅助排放项]
f₂ = Σ EMI(i),  i = 1..24
```

### E. 功率平衡

```
L(t) = Nh(t) + Nw(t) + Np(t) + Npump(t) + Nt(t)
Nt(t) = L(t) - [Nh(t) + Nw(t) + Np(t) + Npump(t)]
```

### F. 抽蓄蓄能量

```
V = Zpump × h = 1400 MW × 4 h = 5600 MWh（陕西/甘肃）
C(t+1) = C(t) - Npump(t) / V
约束: C(t) ∈ [0, 1],  C(1) = C(25) = 0.5
```
