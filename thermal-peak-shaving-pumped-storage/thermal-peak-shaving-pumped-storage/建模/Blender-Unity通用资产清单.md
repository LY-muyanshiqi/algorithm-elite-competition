## 六、Blender/Unity 导入与层级结构

### Blender 层级结构（直接复制到大纲视图）

```plaintext
综合能源系统
├─ 抽水蓄能电站
│  ├─ 上水库系统
│  ├─ 输水系统（半透明）
│  ├─ 地下厂房系统（半透明）
│  ├─ 下水库系统
│  └─ 出线与排水系统
├─ 火力发电厂
├─ 光伏发电站
├─ 风力发电站
├─ 电网系统
│  ├─ 220kV电网
│  ├─ 110kV电网
│  ├─ 10kV电网
│  └─ 0.4kV配电网
├─ 用户系统
└─ 地形与环境
```

### Unity 导入设置

- 所有模型导入时勾选 **"Import Materials"和"Import Textures"**
- 缩放因子设置为 1.0（保持米单位）
- 碰撞体：静态物体添加 Mesh Collider，动态物体添加 Box Collider
- LOD 设置：远距离模型使用 LOD1（面数减少 50%），极远距离使用 LOD2（面数减少 80%）

## 七、快速建模优化建议

1. **重复资产使用实例化**：光伏板、风电机、输电铁塔等重复资产使用实例化（Blender：Alt+D；Unity：Prefab），大幅降低场景面数

2. **地下结构半透明处理**：将引水隧洞、地下厂房等地下结构的材质透明度设置为 0.5，实现透视效果

3. **动态效果添加**：
   - 风电机叶片：添加旋转动画（转速 15rpm）
   - 水体：添加水面波纹动画
   - 冷却塔：添加烟雾粒子效果
   - 输电线路：添加轻微晃动动画
