## 一、项目概述

### 1.1 项目背景

在"双碳"目标驱动下，中国正加速构建以新能源为主体的新型电力系统。然而风电、光伏等新能源具有强随机性与间歇性，大规模并网后电网调峰压力剧增。火电机组被迫频繁参与深度调峰，不仅煤耗陡增，碳排放强度也随之恶化。

抽水蓄能是目前技术最成熟、规模最大的储能方式。如何科学调度抽水蓄能电站，在火电调峰深度与系统碳排放之间找到最优平衡点，是一个典型的多目标优化难题——**减碳与保供天然冲突**。

### 1.2 项目定位

本项目构建了一套"**火电深度调峰 × 抽水蓄能调度 × 碳减排核算**"三位一体的多目标优化系统。核心算法采用自主改进的 **NSLDE（Non-dominated Sorting Learning Differential Evolution，基于非支配排序的学习型差分进化）** 算法，融合 Lévy 飞行扰动与混沌初始化机制，在 365天×24小时 = 8760 点的精细时间粒度上求解 Pareto 最优调度方案集，并通过全栈 Streamlit 交互平台实现调度策略的直观呈现与实时参数调整。

### 1.3 核心价值

- **算法创新**：针对标准 NSGA-II 易陷入局部最优的问题，引入 Lévy 飞行扰动 + Logistic 混沌映射初始化，显著提升种群多样性与全局搜索能力
- **工程实用**：基于真实区域电网数据（水电/风电/光伏/负荷），365天×24小时精细粒度，可直接对接调度系统
- **全栈落地**：MATLAB 算法核心 + Python Streamlit 8页可视化平台 + CI/CD 自动化测试，具备完整的产品化路径

## 三、算法核心：NSLDE 多目标优化

### 3.1 算法设计动机

标准 NSGA-II 在处理高维、非凸的电力调度多目标优化问题时存在两个关键短板：
1. **初始种群集中化**：随机初始化导致种群在可行域内分布不均，降低搜索效率
2. **进化后期停滞**：拥挤距离选择机制在 Pareto 前沿密集区域容易丧失多样性

NSLDE 在 NSGA-II 框架上引入三项关键改进：

### 3.2 改进一：Logistic 混沌映射初始化（公式 4-1 ~ 4-4）

$$
y_{n+1} = \mu \cdot y_n \cdot (1 - y_n), \quad \mu = 4
$$

$$
x_{i,j} = x_{min,j} + y_{i,j} \cdot (x_{max,j} - x_{min,j})
$$

用 Logistic 混沌序列替代均匀随机初始化，使初始种群在高维决策空间中具有**更好的遍历性**，避免个体在特定区域内过度集中。

### 3.3 改进二：Lévy 飞行扰动（公式 4-8 ~ 4-14）

在每一代进化后，以概率 $k=0.3$ 对个体施加 Lévy 飞行扰动：

$$
x_i^{new} = x_i + \alpha \oplus \text{Lévy}(\lambda)
$$

采用 Mantegna 算法生成服从 Lévy 分布的随机步长：

$$
s = \frac{\mu}{|\nu|^{1/\beta}}, \quad \beta = 1.5
$$

Lévy 飞行的幂律尾部分布使其兼具**局部精细搜索**（高概率小步长）与**偶尔的大步跳跃**（低概率大步长），有效帮助个体跳出局部 Pareto 前沿的"拥挤陷阱"。

### 3.4 改进三：增强型选择机制（公式 4-5 ~ 4-6）

采用**两阶段选择机制**：
- **第一阶段**：基于 Pareto 支配等级进行初筛
- **第二阶段**：在相同支配等级的个体间，计算拥挤距离（Crowding Distance）进行二次筛选

保留散布最广的个体，确保 Pareto 前沿的均匀覆盖。

### 3.5 算法流程

```
┌──────────────────┐
│ Logistic混沌初始化 │
└────────┬─────────┘
         ↓
┌──────────────────┐
│ 快速非支配排序     │ ← 评估目标: f₁(火电调峰) + f₂(碳排放)
└────────┬─────────┘
         ↓
┌──────────────────┐
│ 差分进化          │ ← 变异(F=0.65) + 交叉(CR=0.9)
│ (DE/rand/1)      │
└────────┬─────────┘
         ↓
┌──────────────────┐
│ Lévy飞行扰动      │ ← 概率k=0.3
└────────┬─────────┘
         ↓
┌──────────────────┐
│ 外部存档维护       │ ← 精英保留 + 拥挤距离截断
└────────┬─────────┘
         ↓
    ←── 循环至 gen=3000 ──→
         ↓
┌──────────────────┐
│ 妥协解筛选         │ ← 从100个Pareto解中优选最优折中方案
└──────────────────┘
```

## 四、优化模型

### 4.1 决策变量

每天优化 24 小时的抽水蓄能调度策略。决策变量为 **23维实数向量** $x = [x_1, ..., x_{23}]$，$x_i \in [0, 1]$，表示第 $i$ 时刻结束时上水库蓄水状态比例。

决策变量维度的解释：24个时刻点产生 23个决策区间（$S_0 \rightarrow S_1, S_1 \rightarrow S_2, ..., S_{23} \rightarrow S_{24}$）。$S_0 = 0.5$（初始半库容），$S_{24} = 0.5$（周期末恢复初始水位约束）。

### 4.2 决策变量编码

每天优化 24 小时的抽水蓄能调度策略。决策变量为 **23维实数向量**：

- $x_1 \sim x_{21}$：各时刻抽蓄水库状态比例（归一化至 $[0, 1]$）
- $x_{22}$：火电调峰深度下限系数（$[0.125, 1]$）
- $x_{23}$：抽蓄最小出力系数（$[0.3125, 0.75]$）

约束：$S_0 = 0.5$（初始半库容），$S_{24} = 0.5$（周期末恢复初始水位）。每天通过 3000 代进化从 100 个 Pareto 解中由 TOPSIS 法自动筛选折中解。

### 4.3 目标函数

**目标一：火电参与调峰容量最小化**

$$
\min f_1 = \sum_{t=1}^{T} P_{thermal,t}
$$

- $P_{thermal,t}$：$t$ 时段火电机组出力 (MW)
- 最小化火电出力 → 最大化新能源消纳与抽蓄调峰替代效果

**目标二：系统碳排放量最小化**

$$
\min f_2 = \sum_{t=1}^{T} S(P_{thermal,t}) \cdot P_{thermal,t}
$$

- $S(P_{thermal,t})$：$t$ 时段火电碳排放强度（吨CO₂/MWh），随负荷率分段变化

### 4.4 分阶段碳排放强度计算

碳减排核算的核心创新在于**火电碳排放强度不是定值，而是随调峰深度分段变化的函数**：

| 调峰阶段 | 负荷率范围 | 碳排放强度构成 | 煤耗参数 |
|----------|-----------|--------------|---------|
| 常规调峰 | > 50% | $E_1 = H_1 \cdot \eta_c \cdot C_{ar} \cdot M_{CO_2} / M_C$ | 300 g/kWh |
| 不投油深度调峰 | 30%~50% | $E_2 = E_1 + \Delta E_{ineff}$（锅炉→汽机效率链衰减） | 330 g/kWh |
| 投油深度调峰 | < 30% | $E_3 = E_1 + \Delta E_{oil}$（投油助燃 + 辅助系统能耗） | 370 g/kWh |

其中：
- $\eta_c = 0.99$（碳氧化率），$C_{ar} = 0.7$（燃煤收到基碳百分比）
- $\Delta E_{ineff}$：汽轮机效率从 45.8%→40.1% 衰减 + 锅炉效率从 95.3%→90.4% 衰减
- $\Delta E_{oil}$：投油燃烧 + 脱硫过程（$p_s=0.01$含硫率，$\eta_s=0.95$脱硫效率）+ 辅助设备能耗

**全工况碳排放强度统一公式**：

$$
S = E_1 \cdot \mathbb{I}_{high} + E_2 \cdot \mathbb{I}_{mid} + E_3 \cdot \mathbb{I}_{low}
$$

其中 $\mathbb{I}$ 为负荷率分段指示函数。这一模型较传统固定排放系数法，精度提升体现在深度调峰工况（低负荷段）的排放捕捉——火电在 30% 负荷率时的单位碳排放可达额定工况的 **1.23 倍**。

### 4.5 约束条件体系

| 约束类型 | 核心公式 | 物理含义 |
|----------|---------|---------|
| 功率平衡 | $P_{load} = P_{thermal} + P_{hydro} + P_{wind} + P_{solar} + P_{pump}$ | 电网实时供需平衡 |
| 水库容量 | $S_{min} \leq S_t \leq S_{max}$ | 上水库物理库容限制 |
| 水库动态 | $S_t = S_{t-1} + \eta_{pump} \cdot P_{pump,t}^+ - P_{pump,t}^- / \eta_{gen}$ | 抽水/发电引起的水量变化 |
| 抽蓄功率 | $-P_{pump}^{max} \leq P_{pump,t} \leq P_{gen}^{max}$ | 抽水蓄能出力边界 |
| 火电出力 | $P_{thermal}^{min} \leq P_{thermal,t} \leq P_{thermal}^{max}$ | 火电机组出力范围 |
| 爬坡速率 | $-r_{down} \leq P_{thermal,t} - P_{thermal,t-1} \leq r_{up}$ | 火电调峰安全约束 |
| 初末水位 | $\|Z_T - Z_{target}\| \leq \Delta Z$ | 调度周期初末水位恢复 |

## 八、社会效益与量化影响

- **碳减排**：通过优化抽水蓄能调度最大化替代火电调峰，年化减碳效益显著。排放核算基于分三阶段负荷率的碳排放强度曲线，较固定系数法更精确地刻画深度调峰工况的额外排放
- **新能源消纳**：抽蓄充当"绿色缓冲器"，将弃风弃光转化为可调度电能，直接提升电网对风电、光伏的接纳能力
- **煤耗经济性**：深度调峰时火电煤耗从 300→370 g/kWh（+23%），抽蓄替代可避免这一效率损失
- **决策支持**：敏感性分析可量化评估抽发效率、装机容量、碳排放系数等参数变化对减碳效果的影响，为抽蓄电站投资决策和电力行业碳配额制定提供量化依据
- **可推广性**：NSLDE 算法框架可迁移至其他抽水蓄能电站、电池储能系统或其他含双目标权衡的能源调度场景
