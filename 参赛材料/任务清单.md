## 一、项目简介

基于 NSLDE 多目标进化算法的抽水蓄能减碳效益优化系统。火电调峰 × 抽蓄调度 × 碳减排核算，365天×24小时全覆盖。

现有基础：MATLAB算法核心 + Streamlit平台 + 软著申请中 + 节能减排国赛三等奖

---

## 二、技术架构（新版）

```
Vue 3 (前端) → Node.js/Express (中间层) → Flask (Python API) → MATLAB (算法引擎)
                    ↑                            ↑
              ECharts 图表                  scipy + numpy 计算
              Three.js 3D                  读.mat 缓存 / 调MATLAB重算
```

## 四、API 接口清单（16个）

```
GET  /api/v1/overview              → 全局KPI + 年度统计
GET  /api/v1/renewable?day=N       → 新能源逐日数据
GET  /api/v1/pumped-storage?day=N  → 抽蓄调度 + 桑基图数据
GET  /api/v1/thermal-carbon        → 火电对比 + 碳减排
GET  /api/v1/pareto?season=N       → Pareto前沿数据
GET  /api/v1/formulas              → 公式定义
POST /api/v1/recalculate           → 调参重算
GET  /api/v1/recalculate/:taskId   → 重算进度（SSE）
GET  /api/v1/scenarios             → 情景模拟
GET  /api/v1/ab-compare            → A/B对比
GET  /api/v1/data/:dataset         → 原始数据
GET  /api/v1/digital-twin/:day     → 3D场景数据
GET  /api/v1/analysis/sensitivity  → 敏感性分析
GET  /api/v1/analysis/trend        → 趋势分析
GET  /api/v1/analysis/statistics   → 统计分析
GET  /api/v1/analysis/decisions    → 决策建议
```
