# 全年抽蓄减碳效益优化计算系统 - 代码解读

## 一、项目概述

本项目采用**NSGA-II多目标遗传算法**，计算抽水蓄能电站在电力系统中的减碳效益。

**优化目标**：
- 目标1：最小化火电调峰深度
- 目标2：最小化碳排放总量

**核心思路**：通过协调火电深度调峰、新能源消纳和抽水蓄能调度，实现电力系统的低碳运行。

## 四、关键代码模块详解

### 4.1 main.m - 主程序入口

**核心功能**：协调整个优化流程

**关键代码段**：

```matlab
% 1. 加载数据
NH = load('hydro.txt');   % 水电出力（365×24）
NW = load('wind.txt');    % 风电出力
NP = load('solar.txt');   % 光伏出力
FH = load('FH.txt');      % 负荷曲线

% 2. 关键参数设置
Zpump = 1400;  % 抽蓄额定功率（MW）
h = 4;         % 蓄能时长（h），容量=1400×4=5600 MWh

% 3. 并行优化（8核）
parpool('local', 8);
parfor i = 1:365  % 365天并行优化
    A(:,:,i) = nslde(Nh, Nw, Np, L, Zpump, h);
end

% 4. 选择折中解
for i = 1:365
    best_num(i) = compromise_solution(A(:,:,i));  % TOPSIS方法
end

% 5. 计算减碳效益
ce = F2(:,3) - F1(:,3);  % 无抽蓄排放 - 有抽蓄排放
CE = sum(ce) / 10000000; % 转换为万吨
```

**功能说明**：
- 加载一年365天×24小时的新能源和负荷数据
- 使用8核CPU并行优化365天
- 从Pareto解集中选择最优折中解
- 计算全年减碳效益（万吨）

### 4.2 nslde.m - NSGA-II优化算法

**核心功能**：实现完整的NSGA-II多目标遗传算法

**算法参数**：
```matlab
pop = 100;   % 种群规模（100个个体）
gen = 3000;  % 迭代次数
```

**NSGA-II算法流程**：

```
┌──────────────────────────────────────────────┐
│          NSGA-II 算法流程                      │
├──────────────────────────────────────────────┤
│ Step 1: 初始化种群（混沌映射）                │
│ Step 2: 非支配排序 + 计算拥挤距离             │
│                                              │
│ Step 3: 迭代优化（3000代）                   │
│    ┌─────────────────────────────────────┐   │
│    │ 3.1 锦标赛选择（50个父母代）         │   │
│    │ 3.2 差分进化交叉（70%概率）           │   │
│    │ 3.3 Levy飞行变异（50%概率）          │   │
│    │ 3.4 评估子代目标函数                 │   │
│    │ 3.5 合并父代+子代=150个              │   │
│    │ 3.6 非支配排序                       │   │
│    │ 3.7 精英保留（选100个下一代）         │   │
│    └─────────────────────────────────────┘   │
│                                              │
│ Step 4: 输出Pareto最优解集（100个）           │
└──────────────────────────────────────────────┘
```

**关键特点**：
- 使用Logistic混沌映射初始化种群，增强多样性
- 采用Levy飞行进行变异，增强全局搜索能力
- 精英保留策略：合并父子代后选择最优100个

### 4.4 evaluate_objective.m - 目标函数评估

**核心功能**：计算每个调度方案的目标函数值

**主要步骤**：

```
Step 1: 蓄能状态初始化
        C(1)=0.5, C(25)=0.5  % 周期约束：始末状态一致

Step 2: 抽蓄调度模拟
        ┌─────────────────────────────────────┐
        │ if C(i+1) ≤ C(i)  → 抽水蓄能        │
        │    Npump(i) = (C(i)-C(i+1)) × V     │
        │                                      │
        │ if C(i+1) > C(i)  → 放水发电         │
        │    Npump(i) = (C(i)-C(i+1)) × V/0.75│
        │                                      │
        │ 约束：|Npump| ≤ 1400 MW              │
        │      |Npump| ≥ 280 MW (20%阈值)     │
        └─────────────────────────────────────┘

Step 3: 计算火电功率
        Nt = L - (Nh+Nw+Np+Npump)  % 负荷 - 新能源 - 抽蓄

Step 4: 碳排放计算
        ┌────────────────────────────────────────┐
        │ 碳排放因子 Ce = Ce1 + Ce2 + Ce3        │
        │                                      │
        │ Ce1 = H × OF × Cc × Mco2/Mc           │
        │      (基本排放，H=供电煤耗)            │
        │                                      │
        │ Ce2 = 效率损失项 + 机械损失项          │
        │      (深度调峰时煤耗增加)              │
        │                                      │
        │ Ce3 = 脱硫等辅助过程的碳排放           │
        │                                      │
        │ EMI(i) = Ce(i) × TH(i)               │
        │ f(2) = sum(EMI)                      │
        └────────────────────────────────────────┘

Step 5: 约束检验
        if |C(25) - 0.5| > 0
            f(1) = f(2) = 999999999999  % 惩罚
```

**碳排放计算逻辑**：

```matlab
碳氧化反应：C + O₂ → CO₂
           12g  + 32g → 44g
           1kg C → 3.67kg CO₂

煤耗等级：
├─ 深度调峰 (TH < 30%THmax): H = 370 g/kWh
├─ 中度调峰 (30-50%THmax):  H = 330 g/kWh
└─ 高负荷 (>50%THmax):      H = 300 g/kWh
```

### 4.5 process.m - 后处理与减碳计算

**功能**：对比有/无抽蓄两种场景的碳排放

**计算流程**：

```
有抽蓄场景：
┌─────────────────────────────────────────────────┐
│ Nn = Nh + Nw + Np + Npump   % 新能源+抽蓄       │
│ Nt = L - Nn                 % 火电功率          │
│ f1 = tanpafangjisuan(...)   % 计算碳排放       │
└─────────────────────────────────────────────────┘
                ↓
无抽蓄场景：
┌─────────────────────────────────────────────────┐
│ Nn2 = Nh + Nw + Np          % 不使用抽蓄        │
│ Nt2 = L - Nn2               % 火电功率更大     │
│ f2 = tanpafangjisuan(...)   % 计算碳排放       │
└─────────────────────────────────────────────────┘
                ↓
减碳效益：
ce = f2(3) - f1(3)            % 吨/年
```

### 4.6 compromise_solution.m - 折中解选择

**功能**：从Pareto前沿选择最优折中解

**方法**：TOPSIS-like方法

```
Pareto前沿（100个非支配解）
        ↓
┌─────────────────────────────────────────────────┐
│ 1. 计算每个目标的最大最小值                       │
│    f1_max, f1_min, f2_max, f2_min               │
│                                                 │
│ 2. 归一化目标函数值                              │
│    x1 = (f1_max - f1) / (f1_max - f1_min)      │
│    x2 = (f2_max - f2) / (f2_max - f2_min)      │
│                                                 │
│ 3. 计算综合得分                                  │
│    X = x1 + x2                                  │
│                                                 │
│ 4. 选择最优解                                    │
│    best_idx = argmax(X)                         │
└─────────────────────────────────────────────────┘
        ↓
最优折中解
```

## 六、优化结果解读

### 6.1 Pareto前沿含义

```
调峰深度(MW) ↑
            │     ● ●  ●
            │   ●        ●
            │  ●           ● ●
            │ ●                ●
            │●                   ●
            ├────────────────────────→ 碳排放(kg)
```

- Pareto前沿上的解互不支配（无法同时改进两个目标）
- 越靠近左下角，解的综合性能越好
- 实际工程中可根据偏好选择合适的解

### 6.2 减碳效益计算

```matlab
ce_daily = F2(:,3) - F1(:,3)    % 每天减碳量(kg)
CE_year  = sum(ce_daily) / 1e7  % 全年减碳量(万吨)
```

## 七、算法优缺点分析

### 7.1 优点

✅ **并行化设计**：使用parfor对365天并行优化，计算效率高
✅ **混沌初始化**：Logistic映射提高种群多样性
✅ **Levy变异**：增强全局搜索能力，避免早熟
✅ **精英保留**：保证最优解不丢失

### 7.2 缺点与改进建议

⚠️ **代码可读性差**：中文乱码注释、变量命名不规范
⚠️ **参数硬编码**：关键参数分散在多个文件中
⚠️ **重复代码**：evaluate_objective和tanpafangjisuan存在大量重复
⚠️ **缺乏可视化**：Pareto前沿和收敛曲线未可视化

**改进建议**：
1. 提取公共函数，减少代码冗余
2. 使用结构体统一管理参数
3. 添加结果可视化功能
