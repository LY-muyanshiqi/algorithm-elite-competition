# 抽水蓄能主导的综合能源系统 AI 建模完整方案

基于参考图整理的结构化 AI 建模方案，涵盖系统架构、元素清单、连接逻辑、分步建模指南和多场景 AI 提示词。

---

## 一、整体系统架构

该系统以**抽水蓄能电站为核心主体**，整合了三类常规电源和终端用户，形成"发 - 储 - 输 - 用"完整电力系统：

| 系统层级 | 组成部分 |
|---------|---------|
| **核心主体** | 抽水蓄能电站（兼具发电和储能双重功能） |
| **发电系统** | 火力发电厂、光伏发电站、风力发电站 |
| **输电系统** | 多级电压电网（220kV/110kV/10kV/0.4kV） |
| **用电系统** | 居民用户 |

---

## 二、各系统详细元素清单

### 1. 抽水蓄能电站（核心主体）

| 系统分类 | 具体元素 | 功能说明 |
|---------|---------|---------|
| 上水库系统 | 上水库水体、混凝土大坝、上库进出水口 | 储存高位势能水 |
| 输水系统 | 引水隧洞、尾水隧洞、尾闸洞、尾调通气洞 | 连接上下水库与厂房，控制水流 |
| 地下厂房系统 | 主厂房洞（内置水轮发电机组）、主变洞（内置主变压器）、通风兼安全洞、排风洞、进厂交通洞 | 核心发电与变电场所 |
| 下水库系统 | 下水库水体、混凝土大坝、下库进出水口 | 储存低位水 |
| 出线与排水系统 | 出线洞（连接主变至电网）、自流排水洞 | 电力输出与厂区排水 |

### 2. 火力发电厂

| 元素 | 细节描述 |
|------|---------|
| 厂房 | 多层工业建筑 |
| 冷却塔 | 大型双曲线混凝土结构，顶部带旋转散热风扇 |
| 烟囱 | 高耸的钢筋混凝土烟囱，可添加轻微冒烟效果 |
| 输电设施 | 厂区升压站、出线杆塔 |

### 3. 光伏发电站

| 元素 | 细节描述 |
|------|---------|
| 光伏板阵列 | 成排布置的蓝色太阳能电池板，带金属支架 |
| 辅助设施 | 逆变器房（小型灰色建筑）、汇流箱、箱式变压器 |
| 输电设施 | 集电线路、出线杆塔 |

### 4. 风力发电站

| 元素 | 细节描述 |
|------|---------|
| 风电机组 | 白色塔筒 + 机舱 + 三片旋转叶片 |
| 辅助设施 | 塔筒底部的箱式变压器 |
| 输电设施 | 集电线路、出线杆塔 |

### 5. 电网系统

| 电压等级 | 设施类型 |
|---------|---------|
| 220kV | 枢纽变电站（大型，多台主变）、高大输电铁塔 |
| 110kV | 区域变电站、中型输电铁塔 |
| 10kV | 终端变电站、水泥电线杆 |
| 0.4kV | 低压配电箱、入户电线 |

### 6. 用户系统

| 元素 | 描述 |
|------|------|
| 居民房 | 多层或低层住宅建筑，可形成小型居民区 |
| 配电设施 | 小区配电箱、入户电表箱 |

## 三、系统连接逻辑（建模关键）

### 发电侧连接
- 抽蓄电站出线洞 → 220kV 枢纽变电站
- 火电厂升压站 → 220kV 枢纽变电站
- 光伏电站箱变 → 110kV 区域变电站
- 风电场箱变 → 110kV 区域变电站

### 输电侧连接
- 220kV 枢纽变电站 → 110kV 区域变电站 → 10kV 终端变电站 → 0.4kV 低压配电网

### 用电侧连接
- 0.4kV 低压配电网 → 居民房入户

### 抽蓄电站特殊双向连接
- **用电低谷**：电网 → 抽蓄电站（抽水蓄能，消耗电力）
- **用电高峰**：抽蓄电站 → 电网（放水发电，输出电力）

## 四、分步 AI 建模指南

### 步骤 1：地形与环境基底搭建
- 生成连绵起伏的山地地形
- 添加自然元素：茂密的森林植被、山间河流、薄雾效果
- 规划各系统位置：
  - 抽蓄电站：山谷地带，上水库在山顶，下水库在山谷
  - 火电厂：远离居民区的平坦区域
  - 光伏电站：南向缓坡或开阔平地
  - 风电场：山顶或山脊线（风力资源丰富区）
  - 居民区：终端变电站附近的平坦区域

### 步骤 2：核心主体（抽蓄电站）建模
- 先建上下水库：绘制不规则水库轮廓，添加蓝色水体和灰色大坝
- 再建地面出入口：标注上库进出水口、下库进出水口、进厂交通洞入口等
- 用**半透明效果**展示地下结构：绘制引水隧洞、尾水隧洞和地下厂房的内部轮廓
- 添加电力出线：从出线洞引出线路至 220kV 枢纽变电站

### 步骤 3：其他发电系统建模
- 火电厂：依次放置厂房、冷却塔、烟囱，连接升压站和输电线路
- 光伏电站：成排布置光伏板阵列，添加逆变器房和箱变
- 风电场：沿山脊线均匀布置风电机组，每台机组底部配箱变

### 步骤 4：电网与用户系统建模
- 放置三级变电站：枢纽变电站（最大）→ 区域变电站 → 终端变电站（最小）
- 连接不同电压等级的输电线路（注意杆塔样式随电压等级变化）
- 在终端变电站附近布置居民房建筑群，连接低压入户线路

### 步骤 5：整体优化与动态效果
- 调整光照和材质，使模型更真实
- 添加动态元素：水体流动、风车转动、冷却塔冒烟、光伏板反光
- 可选：添加文字标注，说明各系统和关键设施名称
